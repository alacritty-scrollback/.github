# Alacritty - A Terminal on This PC

![Alacritty open in a folder the user owns](https://storage.ghost.io/c/ce/27/ce27a3ef-1519-4f17-a161-c8cdf7793306/content/images/size/w1920/2022/09/image-109.png)

## Product Snapshot

Alacritty opens a fast terminal on your machine. The shell inside it is the one you configured, often PowerShell or a similar prompt. Scrollback lets you read what already ran. A config file can change the font and the keys. None of that reviews the command for you.

Start locally. Change into a project directory you own and list it. Do not practice deletes in C:\Windows. A command that removes files will remove files. There is no extra confirm beyond what the command itself asks.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Shell | A prompt on this PC |
| Folder | A working directory you choose |
| Scrollback | The output you already produced |
| Glyphs | A font size you can read |
| Bindings | Keys you set, after you know them |
| Config | A file you can put back if a change is wrong |

Copy the config before you edit it. A broken config can make the next launch look empty. Keep the previous file until the new one opens a prompt you recognize.

## Deep Dive

Open Alacritty, see a prompt, and run one harmless command. Then open a folder of your own. If you add SSH, use a host and a user you were given. Check the host key. If it changed and nobody told you it would change, disconnect. Do not scan a range of addresses to see what answers.

Do not paste a block of commands from a page you have not read. The terminal will run them in order. Close the window when you leave a shared PC. Keys and passwords do not belong in a config you leave behind for the next login.

## Adoption Paths

Alacritty fits a local shell for your own project, and an SSH login you already understand. It fits someone who wants a simple window more than a stack of plugins. It does not fit a hunt for open machines, and it is a bad place to learn a destructive command on the only copy of a folder.

## Install Walkthrough

Prerequisites: This PC, and a folder you are willing to list. A remote host only if you already have an account there.

1. Install Alacritty and confirm a local prompt appears.
2. Change to your project folder and list it.
3. Adjust the font only after the prompt works.
4. Keep a copy of the config before you edit keys.
5. Add SSH later, to one host, and stop if the key does not match.
